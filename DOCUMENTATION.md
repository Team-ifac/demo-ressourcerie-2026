## 🚀 Démarrage rapide

### Accès à la plateforme

1. Visitez [ressourcerie.ifac.fr](https://ressourcerie.ifac.fr)
2. Cliquez sur **"Connexion"** pour vous authentifier
3. Explorez les ressources disponibles

### Première visite

- **Explorer les ressources** : Utilisez la barre de recherche avancée pour trouver des contenus
- **Consulter votre profil** : Accédez à votre espace personnel pour voir vos statistiques
- **Rejoindre le forum** : Posez vos questions et partagez vos expériences

## ✨ Fonctionnalités principales

### 🔍 Recherche avancée

La barre de recherche vous permet de :

- **Rechercher par mots-clés** : Tapez des termes pour trouver des ressources pertinentes
- **Filtrer par tags** : Sélectionnez des tags pour affiner votre recherche
- **Filtrer par thématiques** : Explorez par domaine d'intérêt
- **Filtrer par catégories** : Naviguez par type de ressource

**Astuce** : Utilisez les filtres combinés pour des résultats plus précis.

### 💾 Téléchargement et partage

Pour chaque ressource, vous pouvez :

- **Télécharger le fichier** : Récupérez la ressource en PDF ou autre format
- **Partager sur les réseaux** : Twitter, Facebook, LinkedIn, Email
- **Générer un QR code** : Créez un code QR pour partager rapidement
- **Exporter en PDF** : Téléchargez une version PDF formatée
- **Imprimer** : Accédez à une version optimisée pour l'impression

### ⭐ Favoris et collections

- **Ajouter aux favoris** : Cliquez sur le cœur pour sauvegarder une ressource
- **Créer des collections** : Organisez vos ressources en thèmes personnalisés
- **Partager des collections** : Envoyez vos collections à d'autres utilisateurs

### 💬 Commentaires et notation

- **Laisser un avis** : Évaluez les ressources avec des étoiles (1-5)
- **Ajouter un commentaire** : Partagez votre expérience et vos suggestions
- **Badge "J'ai testé"** : Marquez que vous avez utilisé la ressource

## 📝 Espace contributeur

### Soumettre une ressource

1. Cliquez sur **"Contribuer"** dans le menu principal
2. Remplissez le formulaire avec :
   - **Titre** : Donnez un titre clair et descriptif
   - **Description** : Expliquez le contenu et les objectifs
   - **Catégorie** : Sélectionnez la catégorie appropriée
   - **Tags** : Ajoutez des tags pour faciliter la découverte
   - **Fichier** : Téléchargez votre ressource (PDF, image, document)
3. Cliquez sur **"Soumettre"**

### Processus de validation

- Les ressources sont examinées par notre équipe
- Vous recevrez une notification une fois validée
- Les ressources rejetées vous seront expliquées

### Bonnes pratiques

- Utilisez des titres clairs et descriptifs
- Fournissez une description détaillée
- Incluez des métadonnées pertinentes (durée, public cible, etc.)
- Assurez-vous que le contenu est original ou correctement attribué

## 📚 Collections personnalisées

### Créer une collection

1. Allez dans **"Collections"**
2. Cliquez sur **"Nouvelle collection"**
3. Donnez un nom et une description
4. Sélectionnez la visibilité (privée ou publique)
5. Ajoutez des ressources

### Gérer vos collections

- **Ajouter des ressources** : Cliquez sur le bouton "Ajouter" dans une ressource
- **Réorganiser** : Utilisez le drag-and-drop pour réordonner
- **Partager** : Générez un lien pour partager votre collection
- **Supprimer** : Archivez ou supprimez une collection

## ❓ FAQ

### Comment réinitialiser mon mot de passe ?

1. Cliquez sur **"Connexion"**
2. Sélectionnez **"Mot de passe oublié"**
3. Entrez votre email
4. Suivez les instructions reçues par email

### Comment supprimer mon compte ?

Contactez l'équipe support via le formulaire de contact. Votre compte sera supprimé dans les 7 jours.

### Comment signaler une ressource inappropriée ?

Cliquez sur le bouton **"Signaler"** sur la ressource. Notre équipe examinera le rapport.

### Comment exporter mes données ?

Allez dans **"Paramètres"** > **"Données personnelles"** > **"Exporter mes données"**.

### Quelle est la limite de taille de fichier ?

La taille maximale est de **100 MB** par ressource.

### Comment contacter le support ?

Utilisez le formulaire de contact dans le footer ou envoyez un email à support@ressourcerie-ifac.fr
